# Playmate

Rehearse your part in a play. Upload the script (.docx), pick your character, and Playmate reads
everyone else's lines aloud, then waits for you to say yours and moves on when you go quiet.

Everything runs in the browser in a single file (`index.html`): no server and no build step.

Host it with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root), or open
`index.html` directly in Chrome or Edge on a computer.
